Limits for prompt and agent cells, saved into the run's settings.

| Field                                                                                                                                                    | Type                                                                                                                                                     | Required                                                                                                                                                 | Description                                                                                                                                              |

| `timeout`                                                                                                                                                | *Optional[str]*                                                                                                                                          | :heavy_minus_sign:                                                                                                                                       | Wall-clock limit for each cell, as a duration string such as `90s`. | `concurrency`                                                                                                                                            | *Optional[int]*                                                                                                                                          | :heavy_minus_sign:                                                                                                                                       | Maximum number of cells executing at the same time, 1 to 100.                                                                                            |
