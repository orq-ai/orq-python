# McpToolInput

Executes tools from Model Context Protocol (MCP) servers and gateways. Reference the server or gateway using "key" or "id"; add "tool_id" to attach a single tool, or omit it to attach every tool it exposes.


## Fields

| Field                                                                                                     | Type                                                                                                      | Required                                                                                                  | Description                                                                                               |
| --------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| `type`                                                                                                    | [Optional[models.McpToolInputType]](../models/mcptoolinputtype.md)                                        | :heavy_minus_sign:                                                                                        | MCP tool type                                                                                             |
| `key`                                                                                                     | *Optional[str]*                                                                                           | :heavy_minus_sign:                                                                                        | The key of the MCP server or MCP gateway                                                                  |
| `id`                                                                                                      | *Optional[str]*                                                                                           | :heavy_minus_sign:                                                                                        | The ID of the MCP server or MCP gateway                                                                   |
| `tool_id`                                                                                                 | *Optional[str]*                                                                                           | :heavy_minus_sign:                                                                                        | The ID of a specific tool within the MCP server. Omit to attach every tool the server or gateway exposes. |
| `requires_approval`                                                                                       | *Optional[bool]*                                                                                          | :heavy_minus_sign:                                                                                        | Whether this tool requires approval before execution                                                      |
