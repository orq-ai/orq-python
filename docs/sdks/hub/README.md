# Hub

## Overview

### Available Operations

* [search](#search) - Search hub items
* [get](#get) - Get a hub item

## search

Returns hub items available to the current workspace, sorted by display name.

### Example Usage

<!-- UsageSnippet language="python" operationID="HubSearch" method="get" path="/v2/hub/search" -->
```python
from orq_ai_sdk import Orq
import os


with Orq(
    api_key=os.getenv("ORQ_API_KEY", ""),
) as orq:

    res = orq.hub.search()

    # Handle response
    print(res)

```

## get

Retrieves a hub item available to the current workspace.

### Example Usage

<!-- UsageSnippet language="python" operationID="HubGet" method="get" path="/v2/hub/{id}" -->
```python
from orq_ai_sdk import Orq
import os


with Orq(
    api_key=os.getenv("ORQ_API_KEY", ""),
) as orq:

    res = orq.hub.get(id="<id>")

    # Handle response
```
